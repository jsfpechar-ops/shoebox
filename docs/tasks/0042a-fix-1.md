## 1. Objective

The proto runners already solve this with a Vite alias (`scripts/proto-score.mjs`, lines 14–20). Add the same alias to the Vitest `unit` project, then resume 0042a at step 2. This was the orchestrator's miss in the brief.

## 4. Steps

1. At the top of `vitest.workspace.ts`, after the existing import, add:

```ts
import { fileURLToPath } from 'node:url';

const ROOT = fileURLToPath(new URL('.', import.meta.url));

/** scripts/ is not a workspace package; resolve @shoebox/* to the sources (as scripts/proto-score.mjs does). */
const SHOEBOX_ALIAS = [
  {
    find: /^@shoebox\/(domain|extraction|i18n|testkit|validation)$/,
    replacement: `${ROOT}packages/$1/src/index.ts`,
  },
];
```

2. Replace the anchor with:

```ts
    resolve: { alias: SHOEBOX_ALIAS },
    test: {
      name: 'unit',
      environment: 'node',
```
