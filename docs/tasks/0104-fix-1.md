## 1. Objective

Today, if storing the mail works but queueing `email.received` fails, the webhook answers 503, the sender retries, the row already exists, and the mail is answered "duplicate" and never processed. Fix: `insertEmail` always returns the row id plus whether it was new; on a repeat, the webhook queues the job again (a no-op when it already exists, by job key). Also apply the biome formatting the last run left.
