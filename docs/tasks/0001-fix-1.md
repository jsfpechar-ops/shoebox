## 1. Objective

`pnpm --filter @shoebox/domain test` reports "No test files found": Vitest, run inside `packages/domain`, loads the root multi-project `vitest.config.ts` whose globs do not match from there. Give the package its own config, mark the root package as ESM, rerun the checks and finish brief 0001.

## 2. Context

Root cause (orchestrator): with no config in the package directory, Vitest 4 uses the root `vitest.config.ts` (`test.projects` from `vitest.workspace.ts`), so `packages/domain/test/smoke.test.ts` is not collected. A config file in the package directory takes precedence. The root config stays for root runs (`vitest run --project unit|db|ui`). The root `package.json` has no `"type": "module"`, so the root config is loaded as CommonJS with a warning.

`.env.example` has 12 names; that is correct (the "13" count in 0001 §6 was wrong). The 4 Biome warnings about ignore patterns are not in scope.
